# Kumo Solutions Service Package Playbooks

## Package 1 — Agent Architecture & Reliability Audit (2 weeks)

### Ideal client
SMB or mid-market team already piloting agents but experiencing inconsistency, hallucinations, or unclear operating cost.

### Core promise
Convert agent demos into a controlled, measurable, production-ready architecture baseline.

### Scope
- current-state architecture review
- failure-mode and safety-gap analysis
- model routing + fallback strategy
- validation/evaluation control recommendations
- prioritized remediation roadmap

### Deliverables
- architecture findings report
- risk/control matrix
- recommended target architecture
- 30/60/90-day implementation plan

### Success metrics
- documented reduction plan for failure and cost drivers
- clear owner map for reliability controls

### Pricing posture
Fixed-fee diagnostic engagement with optional implementation sprint follow-on.

## Package 2 — Workflow Automation Sprint (Lead → Follow-up → Invoice)

### Ideal client
Service businesses with repetitive handoffs and owner bottlenecks.

### Core promise
Deploy high-impact automations in 10 business days that reclaim operator time and improve follow-through.

### Scope
- process mapping for 3 selected workflows
- workflow build + integration
- exception and escalation design
- KPI tracking setup
- operator handoff and SOP delivery

### Deliverables
- 3 production automations
- process map + SOP set
- KPI dashboard (hours saved, follow-up consistency, payment cycle)
- stabilization checklist

### Success metrics
- measurable weekly time saved
- decreased dropped follow-ups
- faster invoice/payment cycle

### Pricing posture
Sprint-based fixed package with optional monthly optimization retainer.

## Package 3 — OpenClaw Runtime Cost & Reliability Optimization (1 week)

### Ideal client
Teams running OpenClaw with growing token spend or unstable provider/rate-limit behavior.

### Core promise
Cut avoidable runtime cost while preserving delivery velocity and reliability.

### Scope
- usage baseline and token audit
- model routing policy and fallback sequencing
- cache and context pruning configuration
- local heartbeat offload setup
- budget alerting and runbook

### Deliverables
- before/after cost report
- optimized OpenClaw config profile
- daily/weekly budget monitoring instructions
- incident playbook for rate limits and spend spikes

### Success metrics
- reduced cost per resolved task
- improved continuity during provider limits

### Pricing posture
One-week optimization package + optional managed optimization subscription.

## Package 4 — Regulated Document AI Pilot (3–4 weeks)

### Ideal client
Regulated or high-trust teams handling contracts/policies/regulated documents.

### Core promise
Deploy a governed document AI workflow with confidence scoring, policy boundaries, and escalation controls.

### Scope
- parser benchmark and quality evaluation
- uncertainty/citation requirements
- policy controls + HITL gate
- audit logging and reporting model
- pilot validation with real sample set

### Deliverables
- benchmark report
- governed workflow implementation
- escalation matrix and policy docs
- compliance/audit evidence pack

### Success metrics
- extraction quality uplift vs baseline
- higher citation completeness
- reduced unsafe high-risk outputs

### Pricing posture
Pilot package with staged rollout option.

## Key extracted insights

### 1) “AI Employees” pattern (Claude + connectors + schedules)
- Reusable skills + scheduled tasks can automate recurring intelligence workflows (research briefs, inbox triage, calendar debriefs).
- Connectors (Gmail, Calendar, etc.) transform assistants from chat tools into operations workers.
- Practical lesson: “human-in-the-loop where stakes are high” (e.g., acquisitions/deals), full automation where risk is low.

### 2) Diagram generation via MCP (Excalidraw / Draw.io)
- MCP connectors can turn architecture prompts into editable diagrams quickly.
- Draw.io can be used via local/remote MCP paths and as reusable skills.
- Practical lesson: architecture communication bottleneck can be reduced by prompt-to-diagram workflows.

### 3) BMAD multi-agent method (PM/Architect/Dev/QA role separation)
- Better outcomes when planning, architecture, implementation, and QA are split into specialized agent roles.
- Enforces document-driven continuity (PRD -> architecture -> stories -> implementation) rather than one long chat thread.
- Practical lesson: role-specific prompts and workflow gates reduce “vibe coding” and increase delivery consistency.

### 4) Autoresearch loop (goal -> experiment -> evaluate -> keep winner)
- High leverage for optimization-heavy tasks (model tuning, testing loops, structured research).
- Core value is iterative experiment automation and winner retention.
- Enterprise caveat: requires strong governance and human oversight for safety and reliability.

### 5) Business automation architecture (from operator-heavy to systems-heavy)
- Durable growth comes from integrated systems (conversion website + content engine + AI writing + distribution + workflow automation).
- “Tools are not systems”: disconnected tooling fails; integrated architecture compounds.
- Practical lesson: one editor/operator + AI stack can replace fragmented teams when process is codified.
